# האימון שלי

אפליקציה אישית למעקב אחרי אימון במכון: משקל וחזרות לכל סט, עם הערכים מהאימון הקודם בדהוי.

- עובדת בלי אינטרנט ונשמרת בטלפון בלבד (localStorage). שום נתון לא נשלח לשרת.
- גיבוי: לשונית "גיבוי", קובץ JSON.
- התקנה באנדרואיד: לפתוח את הקישור ב-Chrome, תפריט שלוש הנקודות, "התקנת אפליקציה" או "הוספה למסך הבית".
- שינוי תרגילים: המערך `PROGRAM` בתחילת הסקריפט ב-`index.html`. לא לשנות `id` של תרגיל קיים; תרגיל שיוצא מהתוכנית עובר ל-`RETIRED` כדי שההיסטוריה שלו תישאר.
- תרגילי מוט (`bar`): רושמים משקל לצד אחד, והסה״כ מחושב (מוט + 2 × צד).

מבנה: `index.html` (כל האפליקציה בקובץ אחד), `manifest.webmanifest`, `sw.js` (עבודה בלי רשת), `confetti.js`, אייקונים.
